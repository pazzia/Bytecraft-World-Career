# CodeQuest MVP

Gamified mobile programming puzzle app — Python-first MVP.

MVP includes onboarding, learning map, 20 Python levels, multiple-choice/fill-missing/code-ordering puzzles, XP, stars, lives, streaks, local progress persistence, profile statistics and Hardcore mode with adaptive timers and speed bonuses.

## CI/CD

Every push to `main` runs Flutter analyze/tests, builds a release APK and publishes it as a GitHub Release.

Active repository: `pazzia/Python.io`.
