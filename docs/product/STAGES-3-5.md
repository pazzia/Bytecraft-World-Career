# Пункты 3 и 5 — проверяемые результаты

## Пункт 3: маршрут и последствия действий, 0.8.0

- На главной показаны три этапа: экспедиция, собственный калькулятор, босс. Для текущего шага указаны действие, результат и одна кнопка продолжения.
- Прогресс кода берётся из проверенных компонентов проекта. Старые ответы на вопросы не отображаются как проверенная программа.
- Экран проекта показывает его место в общем маршруте. Заблокированный босс ведёт к фактически необходимому этапу.
- Покупка улучшения привязана к показанному уровню и цене. Повторный тап не покупает следующий уровень; при отказе сохранения монеты не списываются. После покупки показаны стоимость и эффект.
- Проверки: состояния маршрута, узкий экран с увеличенным шрифтом, параллельные покупки, существующий полный путь экспедиция → код → босс, Android smoke с проверкой нового маршрута.

Техническая приёмка требует успешного CI. Понятность для новых пользователей ещё нужно проверить наблюдением их первых сессий; автоматические проверки не заменяют этот результат.

## Пункт 5: закрепление ошибок

Следующий последовательный шаг после проверки пункта 3: связь с подтемой, другой пример для самостоятельного решения, сохранение доказательства закрепления. Правильный ответ после показа разбора той же задачи сам по себе не подтверждает исправление ошибки.
