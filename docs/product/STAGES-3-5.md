# Пункты 3 и 5 — проверяемые результаты

## Пункт 3: маршрут и последствия действий, 0.8.0

- На главной показаны три этапа: экспедиция, собственный калькулятор, босс. Для текущего шага указаны действие, результат и одна кнопка продолжения.
- Прогресс кода берётся из проверенных компонентов проекта. Старые ответы на вопросы не отображаются как проверенная программа.
- Экран проекта показывает его место в общем маршруте. Заблокированный босс ведёт к фактически необходимому этапу.
- Покупка улучшения привязана к показанному уровню и цене. Повторный тап не покупает следующий уровень; при отказе сохранения монеты не списываются. После покупки показаны стоимость и эффект.
- Проверки: состояния маршрута, узкий экран с увеличенным шрифтом, параллельные покупки, существующий полный путь экспедиция → код → босс, Android smoke с проверкой нового маршрута.

Техническая приёмка пройдена: [CI 39310690428](https://github.com/pazzia/Bytecraft-World-Career/actions/runs/39310690428), включая полный набор тестов, подписанный Android APK и запуск в эмуляторе. Понятность для новых пользователей ещё нужно проверить наблюдением их первых сессий; автоматические проверки не заменяют этот результат.

## Пункт 5: закрепление ошибок

Реализация 0.9.0:

- Ошибки курса, практических задач и игровых режимов сохраняются по конкретной подтеме. В DNA доступны проверки как из игрового раздела, так и из журнала ошибок.
- В каталоге 1914 примеров для 267 подтем и задач: 100 подтем DNA, 106 тем курса, 47 задач практики и 14 игровых понятий. Программы исполняются для вычисления ответов; два сценария выбора инструмента используют варианты ответа, поскольку запуск процессов недоступен в Pyodide.
- Первоначальное задание и уже разобранные примеры исключаются. После неверного ответа следующая попытка использует другой пример; по возможности также другой результат, чтобы нельзя было просто скопировать показанный ответ.
- В практике исключены исходные видимые тестовые данные. Проверочные программы сохраняют алгоритм, меняют буквальные входные данные и имеют короткий вывод для телефона.
- Правильный ответ в первоначальной тренировке не уменьшает число незакреплённых ошибок. Только отдельное самостоятельное решение закрывает конкретную запись и выдаёт награду 30 XP / 12 монет до бонусов города.
- Подтверждение содержит пример, отпечаток кода и входных данных, время проверки. Оно сохраняется атомарно с наградой; повторная отправка и устаревший результат не оплачиваются. Новая ошибка открывает подтему заново, сохраняя прежние подтверждения.
- Старые общие счётчики сохраняются без выдуманной привязки к подтемам. Если незнакомые примеры исчерпаны, ошибка остаётся незакреплённой и награда недоступна.

Проверки: восстановление после перезапуска, неверный ответ и смена примера, параллельные отправки, отказ записи, повторная ошибка, отсутствие подмены исходным примером, полный экранный сценарий из журнала. Полный CI остаётся обязательным перед выпуском 0.9.0. Эти подтверждения относятся к учебным задачам, а не к профессиональной аттестации.
