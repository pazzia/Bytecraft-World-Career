## Исправленная цепочка

1. Push в main или ручной запуск `World Career Android`.
2. Проверки контента, Flutter analyze и тесты, сборка и подпись APK.
3. Установка и запуск APK в эмуляторе Android.
4. `publish` получает APK из того же запуска; создаёт draft Release с APK, SHA-256 и `build-info.json`.
5. Скачивает загруженный APK, побайтно сравнивает его с собранным и проверяет SHA-256.
6. Только после успешной проверки публикует Release и обновляет постоянную ссылку из README.

Активная сборка не отменяется следующим push. Тег включает номер сборки и попытку, поэтому повторный запуск не заменяет уже опубликованный APK. Версия приложения берётся из `pubspec.yaml`; точный коммит и номер CI записываются рядом с APK.

Статус публикации проверяется по наличию успешного job `publish` и файла в Releases, а не по одному лишь созданию коммита. При сбое `publish` можно повторить через Re-run failed jobs в Actions.
