# Исполняемый проект: калькулятор

Этап 4, кандидат 0.7.0. Проверки CI обязательны до закрытия этапа.

Проект открывается после пяти этапов экспедиции. Пользователь пишет свою программу на Python в пустом редакторе. Четыре компонента: calculate с четырьмя операциями, список history с результатами, ошибки деления на ноль/неизвестной операции, run_calculator с разбором строк и понятными сообщениями. Проверки запускаются в существующем PythonRunner на устройстве; каждый шаг повторно проверяет и предыдущие функции. Количество проверок: 5, 6, 9, 14.

Черновик автоматически сохраняется после паузы ввода, явно кнопкой и до проверки. При уходе выполняется дополнительная попытка сохранения. Проверенный финальный код хранится отдельно от изменяемого черновика и доступен для копирования. Неисправленный черновик не заменяет последнюю рабочую программу.

Награда компонента: 45 XP и 25 монет до бонусов зданий; после неудачных проверок — 22 XP. Для миграции компонентов, за которые уже начислялась награда в старом проекте-вопроснике, повторной валюты нет. Квитанцией служит завершённый номер этапа вместе с сохранённым результатом. Изменившийся во время проверки код, неполный ответ проверяющего скрипта, неправильный nonce, недоступный Python или отказ сохранения не продвигают этап и не выдают награду.

Босс требует отдельный флаг hasVerifiedProject, который выдаётся после всех 14 проверок кода. Старые ответы на четыре вопроса больше не могут открыть босса. Старые монеты и достижения не удаляются.

Проверки Python проверяются независимо в CPython эталонной программой и намеренно ошибочными решениями; CI повторяет их. Тесты сервиса проверяют перезапуск, гонки, изменение кода во время выполнения, отказ записи и сохранение последней рабочей версии. Это проверка функциональности программы, а не профессиональная аттестация автора.
