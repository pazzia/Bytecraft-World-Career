## Отдельные артефакты

Готовый APK 0.4.3 остаётся ранее выданной сборкой. APK и временные build-каталоги в исходники не добавлялись; последующие APK создаёт Actions. Подготовленные изменения 0.4.4 должны пройти проверки нового репозитория.

Ключи подписи и другие секреты не являются содержимым Git. Старые настройки / кэши Actions и подключённые сервисы требуют отдельной настройки; история Git не переносит их автоматически.
