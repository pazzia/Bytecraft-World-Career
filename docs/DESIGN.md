# Дизайн Bytecraft: «код как клавиатура»

Источник — холст с макетами «Bytecraft — макеты» (9 экранов). Код темы: `lib/core/theme/`, общие виджеты: `lib/shared/widgets/`.

## Идея

Главный элемент — **клавиша** (`Keycap`): светлая или цветная грань и плотное нижнее ребро на 4 px. При нажатии грань проседает на ребро, срабатывает лёгкая вибрация. Клавишами сделаны кнопки, варианты ответа, токены кода, строки в «порядке строк», узлы карты и значки достижений. Код всегда лежит на тёмной **доске** (`CodeBoard`).

Всё остальное намеренно спокойное: без градиентов, без капс-заголовков, без эмодзи, одна тень — ребро клавиши.

## Палитра

| Токен | Hex | Роль |
|---|---|---|
| Paper | `#EEF2F7` | фон |
| Ink | `#1B2838` | текст, доска с кодом |
| Python Blue | `#2F6DB5` | основное действие, текущий уровень |
| Python Yellow | `#FFD43B` | только награды: звёзды, «Продолжить» к награде, вставленный токен |
| Green | `#188A5D` | верно, пройдено |
| Red | `#D23C42` | ошибка, жизни |
| Ember | `#FF5B1F` | серия и режим «На время» |
| Night | `#142033` | тёмная тема и режим «На время» |

Режим «На время» всегда ночной (`AppTheme.timed`), независимо от системной темы, и с огненным акцентом: кнопки, переключатель, «фитиль» таймера над уровнем.

## Шрифты

Встроены в приложение (`assets/fonts`, лицензия OFL), работают офлайн:

- **Onest** — интерфейс. Шкала 30 / 26 / 24 / 20 / 17 / 15 / 13.
- **JetBrains Mono** — код и токены, 17–20 px.

## Доступность

- Касание не меньше 48 px, клавиши ответов 56–64 px.
- У всех клавиш и строк кода есть подписи для экранного диктора.
- В «порядке строк» без перетаскивания есть действия «Поднять выше / Опустить ниже».
- Если в системе включено «уменьшить движение», анимации звёзд и нажатий отключаются.
- Жёлтый цвет используется только с тёмным текстом или на тёмной доске.
