# Версия для iOS

iOS-версия — то же Flutter-приложение в iOS-оболочке. CI собирает её на macOS в задании `ios` (`.github/workflows/android.yml`):

1. `flutter create --platforms=ios` создаёт оболочку `ios/`; в `Info.plist` ставятся имя «Bytecraft», разрешение на `http://127.0.0.1` (`NSAllowsLocalNetworking` — песочница Python грузится с локального сервера) и иконка из `tool/ios/AppIcon-1024.png`.
2. В iOS Simulator запускается `integration_test/device_smoke_test.dart`: приложение проходит заставку, а Python в WebView (WKWebView) выполняет программы — `print`, `input`, потоки, `asyncio`, ошибки, бесконечный цикл с перезапуском.
3. Делаются скриншоты приложения в симуляторе (артефакт `ios-screens`).
4. Собирается `bytecraft-<версия>-build<N>.ipa` без подписи. Сборки из `main` публикуются в **Releases** рядом с APK.

## Как поставить на iPhone

Apple разрешает ставить приложения не из App Store только с подписью. Без платного аккаунта разработчика это делается бесплатным Apple ID через программу на компьютере:

**Sideloadly** (Windows или macOS, https://sideloadly.io):
1. Скачайте `.ipa` из последнего релиза.
2. Подключите iPhone кабелем, откройте Sideloadly, перетащите туда `.ipa`, введите свой Apple ID и нажмите Start.
3. На iPhone: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → **Доверять**.
4. iOS 16 и новее: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить, перезагрузить.

**AltStore** (https://altstore.io) работает так же и сам продлевает подпись по Wi‑Fi, пока на компьютере запущен AltServer.

Ограничения бесплатного Apple ID: подпись действует **7 дней** (потом переподписать той же программой — прогресс сохранится), не больше 3 таких приложений на устройстве.

## TestFlight и App Store

Для установки по ссылке через TestFlight и для публикации нужен **Apple Developer Program** (99 $ в год). Когда аккаунт появится, в секреты репозитория добавляются сертификат распространения (`.p12` и пароль), профиль и ключ App Store Connect API — и CI сможет подписывать сборку и выгружать её в TestFlight.
