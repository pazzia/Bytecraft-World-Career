# Макеты

Папка на каждую задачу из `../tasks/`. Внутри — PNG из ChatGPT:

- `light.png` — светлая тема (для экранов забега — ночная);
- `dark.png` — тёмная тема, если задача её требует;
- `<вариант>.png` — дополнительные состояния, например `empty.png`.

После визы критика в `../README.md` у задачи ставится статус «утверждено».
