# Дизайн Bytecraft

Здесь лежат задания на отрисовку экранов в ChatGPT и готовые макеты. Источник правды — `SPEC.md`: дизайн-ревью и спецификация UX v2. 18 октября 2026 его утвердил субагент-критик, решения по механикам подтвердил владелец.

## Что где лежит

| Путь | Что там |
| --- | --- |
| `SPEC.md` | полная спецификация: цвета, шрифты, компоненты, словарь, правила механик, все экраны |
| `tasks/` | по одному файлу на экран: готовые промпты для ChatGPT, выдержка из спецификации, приёмка |
| `prompts/prefixes.md` | общие префиксы промптов для новых экранов |
| `renders/<задача>/` | готовые макеты: `light.png`, `dark.png`, варианты |

## Как работаем

1. Берём следующую задачу из таблицы по порядку этапов.
2. Копируем промпт из файла задачи в ChatGPT целиком.
3. Кладём результат в `renders/<номер>-<экран>/` и ставим статус «на ревизии».
4. Субагент-критик сверяет макет со `SPEC.md`: тексты, цвета, размеры, состояния. Без его визы макет не утверждён.
5. Утверждённый макет получает статус «утверждено» и становится эталоном для задачи в коде.

Если в ходе отрисовки нужно изменить спецификацию, сначала меняется `SPEC.md` и проходит ревизию критика, потом промпт.

Статусы: не начато → на ревизии → утверждено (или «на доработке» с замечаниями критика).
